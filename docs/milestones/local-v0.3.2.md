# GitHubSP v0.3.2 本地候选

此版本为阶段 M0 的本地验证产物，未提交、推送或发布。

- 限速继续按 KiB/s 存储，设置和队列统一按十进制 MB/s 显示，旧值保存不漂移。
- 新增 `scripts/verify-desktop.ps1`，为前端测试/构建、核心与宿主回归、Clippy、格式及可选打包保留结果和日志。
- 新增当前 Tauri 桌面入口的 CI 工作流，保留历史 Slint 工作流。CI 只有读取仓库和上传验证产物的权限，不发布 Release。
- 打包按当前版本精确选取安装器，避免后续迭代被旧版安装器干扰。

正常权限下 125 项核心测试、7 项宿主测试、5 项前端测试、生产构建、Clippy 和格式检查通过。受限沙箱的文件替换/锁检查失败记录单独保留。使用现有引擎真实下载 v0.3.1 的公开校验文件，官方 SHA-256 校验通过。

候选位于 `artifacts/build/roadmap-v0.3.2/`，包含安装器、免安装 ZIP、校验和及依赖许可。打包工具首次因沙箱无法访问下载源而失败，正常权限下对已构建程序完成 NSIS 打包。

干净系统安装/卸载、缺失 WebView2 及多 DPI/多显示器未计为通过。后续阶段的工作区实现会继续迭代，v0.3.2 候选目录保留这一阶段的程序。
