# GitHubSP v0.4.0 本地候选

本地功能迭代，未提交、推送或发布；稳定下载仍为 v0.3.1。

- 版本页按平台、架构和安装版/便携版偏好展示匹配理由，仅在唯一匹配时自动勾选；歧义、未知命名和不完整元数据需手动选择。
- “保存项目偏好”与收藏关注规则共用数据，首次保存会明确提示同时收藏。既有显式通配符及 `{version}` 规则保留原语义；保存的新偏好与通配符共同约束。
- 收藏自动下载复用相同 Rust 选择逻辑，不再按文件大小猜测同类候选。
- 设置新增直连、系统代理和自定义 HTTP/HTTPS 代理，保存后重启生效；不支持内嵌账号密码及 SOCKS。元数据与附件使用同一网络配置，既有公共镜像保持独立的线路选择功能。
- 继续保留 v0.3.2 的限速显示修复、验证脚本和当前入口 CI。

配置向后兼容：`WatchRule.preference` 为可选字段，旧记录可以加载；`Settings.network` 缺失时为直连。备份和重新加载已覆盖这些字段。启用当前 reqwest 版本的系统代理功能，新增其三个平台依赖记录，没有升级已有依赖版本。

验证证据在 `artifacts/verification/roadmap-20261108/`。新增回归覆盖附件歧义、未知架构、通用包、显式规则、代理地址与凭据拒绝、代理接收两类目标，以及偏好/代理备份恢复。真实 WebView2/IPC 检查在 `m1-native-04` 通过，包含两种窗口尺寸和深浅主题、项目偏好保存及重启恢复。公开安装附件完成暂停、退出、重启和续传，成品与官方校验文件一致；测试文件未执行。

初次原生检查的启动/推送时序问题及一次固定直连超时记录保留。正确构建后使用自动线路完成验收，独立核心复核也通过官方摘要校验。干净系统安装、缺失 WebView2 和多 DPI/多显示器仍是独立未验收项。
