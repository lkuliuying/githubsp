# v0.6.0-alpha.1 本地候选

新增更新中心、项目分组与标签、完整 Release 说明。新关注只建立基线，后续每个仓库/标签只生成一个事件；Atom/API 身份转换补全元数据，保留同一事件及处理结果。已看到、忽略此版本和已下载附件分别保存，读取列表或详情不算已读。

更新记录沿用 SQLite 的独立 `update_ledger` 设置条目，与收藏/关注变更在事务中保存，应用备份包含记录和游标。游标带数据标识，可重复读取；与其他数据库或恢复点不符时明确拒绝。正文只在详情中返回，常规快照和 Agent 列表不携带整篇正文。桌面按最近发现顺序浏览；Agent 按增量顺序读取。

Harness 新增 `githubsp_updates`、`githubsp_update` 和 `githubsp_project_labels`。实际原生宿主验收通过后再将同一工具定义开放给 MCP，后者不依赖 Harness。

验证证据在 `artifacts/verification/roadmap-20261108/`：

- `m3-native-01`：16 项真实 WebView2/Harness 检查及浅深色预览，包含完整来源正文、读取不已读、游标重读、显式忽略、重启持久化、标签、共享队列和插件重载。
- `m3-mcp-02`：18 项通过，进一步核对 MCP 读取与显式处理能在 Harness 中反映，脚本正常退出。
- `m3-checks`：135 核心、9 宿主、5 前端、3 插件测试、前端构建与 Clippy 通过；末尾格式检查发现一处测试断言未排版，已修正，`format-recheck.json` 记录复查通过。

真实更新检查使用公开仓库与隔离库中明确设置的旧版本基线，没有创建远程 Release。首次原生验收的测试父进程因日志管道未释放而滞留，已仅清理该测试进程并修正验收驱动；后续完整跨端验收正常退出。实际宿主仍限定已验证版本，Harness 尚未做真实模型回合验证。
