## 行为说明

- 检查间隔仅控制自动检查；手动“检查更新”不受限。单轮检查同一时间只处理一项收藏，取消在当前网络请求返回后生效。
- 失败退避：30 分钟、1 小时、2 小时、4 小时、6 小时封顶；成功后 `next_check = now + 所选间隔`。
- 自动下载只处理新发现且版本发生变化的收藏；首次检查仅建立基线。附件模式 `auto` 优先当前平台安装包，`{version}` 会替换为最新 tag。
- Atom 降级仅在 REST 请求失败或限流时触发，结果标记 `source=atom` 并在界面提示附件可能不完整。
- 未读持久化在设置键 `watch_state`；忽略单个或全部会写入 `acked_release_id`，不会删除收藏。
- 日志位于应用数据目录 `logs/githubsp.log`，单文件 5 MB，保留一个 `.previous`；不记录令牌、Cookie 或剪贴板内容。
- 动效使用 `ui/motion.slint` 的 8 个令牌（`instant 80 / press 90 / fast 120 / hover 140 / base 180 / slow 260 / ripple 300 / emphasized 360`）：按钮悬停/按下色差、图标旋转与点击涟漪；统一全局侧栏使用 14px 文字、20px 图标与 40px 主入口，窗口不足 900px 时收为图标导航，下载模块入口移至正文顶部；设置的五个模块采用横向分区。下载队列正文达到 760px 时显示六列表格，较窄时显示双行记录；历史记录按需展开详情，收藏卡片按实际内容确定高度。版本列表行按下有底色反馈。设置“减少界面动效”或 Windows 关闭“显示动画”时令牌全部归零。按下缩放因 Slint 的 `percent` 类型不可 animate 而未实现（计划书 D11）。

## 已知限制

- 无代码签名，Windows SmartScreen 可能提示；签名仍在后续里程碑。
- 提醒窗为应用内独立窗口，关闭应用后不保留系统通知；未读状态在下次启动恢复。
- 手动取消不会中断正在进行的单个 HTTP 请求，最长等待一次请求超时。
