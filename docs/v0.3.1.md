# GitHubSP v0.3.1

发布日期：2026-11-07。当前桌面入口采用 **Tauri 2 + React + TypeScript + Rust**，同时提供 Windows x64 安装版和免安装版。

## 更新内容

- 重做六个模块：下载队列、新建下载、历史、收藏、线路检测和设置，采用灰白主色与黑灰操作按钮。
- 参考 magpie 的页面骨架和导航体验，增加弹簧导航滑块、页面淡入、减少动态，以及切页后的输入、筛选、选择和滚动位置保留。
- 设置页采用分类标签、跨分类搜索和“关／开”分段控件；保留未保存草稿与原有确认流程。
- 使用原创几何包裹图标，接入应用、托盘及安装器资源。
- 继续复用 Rust 下载引擎、SQLite 和数据目录，保留暂停恢复、目录检查、重复项识别、下载前确认、换线确认、备份与退出保存。
- 保留 magpie、cc-switch、Motrix 的版权及 MIT 文本，并随两种分发提供完整运行依赖许可。

## 下载与运行

| 附件 | 用途 |
| --- | --- |
| `GitHubSP-v0.3.1-windows-x64-Setup.exe` | Windows x64 安装版；缺少 WebView2 时下载并安装 Evergreen Runtime。 |
| `GitHubSP-v0.3.1-windows-x64-Portable.zip` | 免安装版；解压完整目录后运行 `GitHubSP.exe`，需要系统已有 WebView2。 |
| `SHA256SUMS.txt` | 校验上述两种分发文件的 SHA-256。 |
| `LICENSE`、`THIRD_PARTY_NOTICES.md`、`FRONTEND-LICENSES.txt`、`RUST-LICENSES.txt` | 项目及第三方许可。 |

请先退出旧版再启动新版。普通安装和免安装模式沿用正式数据位置，不自动导入试用数据；需要随身数据时，在 exe 旁创建空文件 `portable-mode.flag`，使用同目录 `data/`。独立试用可使用 `--data-dir <绝对路径>`。

历史 Slint 版与新版运行时条件不同，请从本发布页选择新的安装包或 ZIP。程序不会自动安装更新或运行下载的文件。本次没有提供含固定 WebView2 Runtime 的完整离线包。

## 验证边界

本轮发布检查覆盖前端测试与生产构建、核心回归、应用版本资源、分发包与 ZIP 内程序一致性、校验和及许可文件。已有模拟 IPC 界面检查覆盖三种窗口尺寸、深浅主题、状态保留、焦点隔离和异步确认；模拟检查不替代真实网络或安装验收。

程序未进行 Windows 代码签名。干净系统安装/卸载、缺失 WebView2、多 DPI/多显示器及真实网络完整下载仍需专项验收。原有限速保存和队列显示的单位差异尚未统一。
