# GitHubSP v0.5.0

发布日期：2026-11-20。宽屏窗口不再在右边空出一大块：下载队列、新建下载、我的软件在右侧多了一栏常用信息，任务和软件详情也改到这一栏里显示。下载核心和数据格式与 v0.4.3 相同。

## 更新内容

### 宽屏右侧栏

以前页面内容最宽 1440 像素并靠左排列，窗口较宽时右边整块空白。现在页面宽度达到 1320 像素时，右侧会出现一栏（约 320～400 像素宽）；窗口更窄时保持原来的布局，不受影响。

- **下载队列**
  - **今日概览**：今天已下载多少、完成了几个，以及最近 60 秒的速度折线。
  - **我的软件有更新**：列出可以更新的软件，直接点「下载」加入队列；都是最新时显示上次检查时间和「检查更新」。
  - **最近完成**：最近完成的 4 个文件，可以直接打开所在文件夹；「全部」跳到已完成列表。
- **我的软件**
  - 没有选中软件时显示**最近发布**，点项目名查看详情。
  - 切到「更新动态」时，右侧列出可更新的软件和「全部更新」。
- **新建下载**
  - **从我的软件挑选**：点一下关注的软件就读取它的版本。
  - **最近下载过**：最近下载过、但没有关注的仓库。
  - **可以粘贴这些地址**：仓库地址、Release 页面、附件链接、视频简介和帖子里的地址。
- **详情不再挤压列表**：宽屏时点开任务详情或软件详情，会显示在右侧栏里，列表宽度保持不变。

「今日已下载」按最近 100 条完成记录统计；一天完成超过 100 个文件时，数字后面会显示「+」。

## 下载与运行

| 附件 | 用途 |
| --- | --- |
| `GitHubSP-v0.5.0-windows-x64-Setup.exe` | Windows x64 安装版；缺少 WebView2 时下载并安装 Evergreen Runtime。 |
| `GitHubSP-v0.5.0-windows-x64-Portable.zip` | 免安装版；解压完整目录后运行 `GitHubSP.exe`，需要系统已有 WebView2。 |
| `SHA256SUMS.txt` | 校验上述两种分发文件的 SHA-256。 |
| `LICENSE`、`THIRD_PARTY_NOTICES.md`、`FRONTEND-LICENSES.txt`、`RUST-LICENSES.txt` | 项目及第三方许可。 |

请先完全退出旧版（包括托盘图标）再启动新版。v0.5.0 沿用 v0.4.3 的数据目录和数据格式，可以直接覆盖安装，也可以换回 v0.4.3。程序不会自动安装更新，也不会运行下载的文件。
