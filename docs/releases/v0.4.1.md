# GitHubSP v0.4.1

发布日期：2026-11-19。界面细节升级版，下载核心、数据格式和 Agent 工具与 v0.4.0 相同。

## 更新内容

### 下载队列

- **拖动调整下载顺序**：有两个以上排队任务时，鼠标移到排队任务的图标上会变成把手，按住上下拖动即可调整先后，松手立即生效。拖动中按 Esc 取消；用键盘选中把手后，按上下方向键逐位移动。任务详情里的「提前 / 延后 / 优先下载」照常可用。
- **列表顺序调整**：正在下载的任务排在最上面，排队任务按下载先后接在后面，暂停、失败等其余任务放在最后。
- **顶栏直接改限速**：点顶栏的「限速」（没有限速时显示「不限速」），弹出小窗，可以点 1 / 5 / 10 / 20 MB/s 或不限速，也可以输入数值，立即对正在下载的任务生效。顶栏的限速写法更易读，例如「限速 49 KB/s」。
- **进度条**：绘制更顺滑；检测线路、等待网络、重试、校验时，已下载的部分上会扫过一道光带，表示程序仍在处理。

### 细节动效

- 标签的选中底色会滑到新选中的标签上：下载队列的状态标签、已完成里的「下载完成 / 已取消」、我的软件的筛选，以及「软件 / 更新动态」。
- 侧边栏角标、页面标题计数、顶栏统计和标签计数变化时，数字会滚动到新值。
- 复制链接、复制路径后，按钮显示对勾和「已复制」，稍后复原。任务详情的保存位置旁新增复制按钮，已完成的任务也能复制路径。
- 所有新动效都遵循「设置 → 通用 → 显示」里的「减少界面动效」，以及 Windows 的动画效果设置。

这些交互参考了 [cult-ui](https://github.com/nolly-studio/cult-ui)（MIT），用本项目自己的样式重写，没有新增前端依赖。

## 下载与运行

| 附件 | 用途 |
| --- | --- |
| `GitHubSP-v0.4.1-windows-x64-Setup.exe` | Windows x64 安装版；缺少 WebView2 时下载并安装 Evergreen Runtime。 |
| `GitHubSP-v0.4.1-windows-x64-Portable.zip` | 免安装版；解压完整目录后运行 `GitHubSP.exe`，需要系统已有 WebView2。 |
| `SHA256SUMS.txt` | 校验上述两种分发文件的 SHA-256。 |
| `LICENSE`、`THIRD_PARTY_NOTICES.md`、`FRONTEND-LICENSES.txt`、`RUST-LICENSES.txt` | 项目及第三方许可。 |

请先完全退出旧版（包括托盘图标）再启动新版。v0.4.1 沿用 v0.4.0 的数据目录和数据格式，可以直接覆盖安装，也可以换回 v0.4.0。程序不会自动安装更新，也不会运行下载的文件。

## 验证边界

- 发布前回归：核心、Tauri 宿主和前端测试，以及生产构建、Clippy、格式检查和安装包打包。新增测试覆盖拖动到指定位置和顶栏限速写法。
- 两批界面改动都用隔离数据，在真实桌面程序中用真实公开附件下载，脚本操作并截图核对浅色、深色和 760px 宽度，并经过试用。
- 已知：CI 中核心测试 `manual_detection_keeps_download_progress_queue_pause_cancel_and_resume_working` 在 GitHub 的运行环境里不稳定（v0.4.0 起即如此），本地稳定通过。
- 窗口宽度小于 1040px 时，顶栏统计（含限速入口）整体隐藏，与 v0.4.0 一致；可在「设置 → 下载」修改限速。
- 程序未进行 Windows 代码签名。

改动说明见[界面细节升级记录](../design/2026-11-19-cult-ui-polish.md)。
