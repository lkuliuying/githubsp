# GitHubSP v0.4.2

发布日期：2026-11-19。新增剪贴板链接识别，并优化列表和新建下载界面。下载核心、数据格式和 Agent 工具与 v0.4.1 相同。

## 更新内容

### 识别剪贴板中的 GitHub 链接

- **打开应用就能下载**：在浏览器里复制了 GitHub 仓库、版本页或附件链接后，打开 GitHubSP，顶部会出现提示条，例如「剪贴板里有 GitHub 链接：owner/repo」。仓库和版本页点「读取版本」，会跳到新建下载并自动读取版本列表；附件链接点「去下载」，会填好链接，确认保存位置后即可下载。
- **不只在启动时**：应用开着时，从托盘或再次双击图标唤起窗口、用 Alt+Tab 切回来，也会检测新复制的链接。
- **识别宽松**：链接夹在一段文字里、带 `?tab=…` 或 `#…`、是 `/tree/main`、`/issues/1` 之类的子页面或 `.git` 克隆地址，都能认出对应的仓库；GitHub 站内功能页和 gist 会被忽略。
- **不重复打扰**：同一份剪贴板内容只提示一次，在本应用里复制的链接不会提示。
- **Ctrl+V 直达**：在不是输入框的地方按 Ctrl+V，直接带着剪贴板里的链接打开新建下载。
- **隐私**：剪贴板只在本机识别，界面只拿到识别出的链接，不保存也不记录剪贴板内容。可在「设置 → 通用 → 窗口与通知」关闭「识别剪贴板中的 GitHub 链接」。

### 界面优化

- **列表底栏跟随内容**：下载队列和我的软件中，记录少时「共 N 条 · 翻页」紧贴最后一行；超出一屏时列表内部滚动，底栏固定在底部。
- **字体更清爽**：按钮、标签和分段切换不再把中文显示成粗体，文件名和标题仍保留粗体。
- **已完成列表**：文件存在的记录改用灰色文件图标；文件缺失的记录图标淡化，只有「文件缺失或已移动」用提醒色。「打开文件夹」和「重新下载」等宽对齐。
- **新建下载**：去掉中间的说明块，保存位置和下载线路紧跟在链接输入框下面。「显示预发布版本」移到「读取版本」旁边，读取过版本后切换会自动重新读取。下载线路下拉框加宽，不再截断文字。
- **图标悬浮提示**：所有纯图标按钮在鼠标停留时显示用途说明，样式跟随深浅色主题。标题栏的最大化按钮按状态显示「最大化 / 还原」，关闭按钮按设置显示「关闭到托盘 / 退出」。

### 修复

- 第一次打开新建下载页时（例如从「我的软件」跳转过来），自动读取版本的结果会被丢弃，页面停在空白状态。

## 下载与运行

| 附件 | 用途 |
| --- | --- |
| `GitHubSP-v0.4.2-windows-x64-Setup.exe` | Windows x64 安装版；缺少 WebView2 时下载并安装 Evergreen Runtime。 |
| `GitHubSP-v0.4.2-windows-x64-Portable.zip` | 免安装版；解压完整目录后运行 `GitHubSP.exe`，需要系统已有 WebView2。 |
| `SHA256SUMS.txt` | 校验上述两种分发文件的 SHA-256。 |
| `LICENSE`、`THIRD_PARTY_NOTICES.md`、`FRONTEND-LICENSES.txt`、`RUST-LICENSES.txt` | 项目及第三方许可。 |

请先完全退出旧版（包括托盘图标）再启动新版。v0.4.2 沿用 v0.4.1 的数据目录和数据格式，可以直接覆盖安装；新增的剪贴板开关对旧数据默认开启，换回 v0.4.1 时会被忽略。程序不会自动安装更新，也不会运行下载的文件。

## 验证边界

- 发布前回归：核心、Tauri 宿主和前端测试，以及生产构建、Clippy、格式检查和安装包打包。新增测试覆盖链接识别（文字中夹带、子页面、克隆地址、站内功能页和 gist 排除、附件去重）和提示文字。
- 用隔离数据在真实桌面程序中核对：启动时和再次唤起窗口时的提示条、「读取版本 / 去下载」跳转、首次打开新建下载页的自动读取、1000 条记录下的列表底栏，以及预发布切换。悬浮提示在浏览器预览中核对了浅色、深色和窗口边缘。三批改动都经过试用。
- 已知：Ctrl+V 直达和用 Alt+Tab 切回时的检测没有做脚本化测试，靠试用确认。
- 程序未进行 Windows 代码签名。
