# GitHubSP v0.4.0

发布日期：2026-11-18。桌面入口继续采用 **Tauri 2 + React + TypeScript + Rust**，同时提供 Windows x64 安装版和免安装版。

## 更新内容

### 界面重新整理

- 侧边栏从 8 项合并为 4 项：**下载队列**（首页）、**新建下载**、**我的软件**、**设置**。下载历史并入队列的「已完成」标签，项目收藏、软件文件库和更新中心合并为「我的软件」，线路检测移到「设置 → 网络」。
- **快速下载栏**：在下载队列顶部粘贴附件链接，回车即可加入队列；粘贴仓库地址会转到新建下载，并自动读取版本。
- **我的软件**：每个项目显示本地版本、最新版本和文件状态，有新版本时可以一键「更新到 vX」或「全部更新」；只下载过、没关注的项目可以一键关注。详情面板提供更新说明、版本记录和本地文件信息。
- **新建下载**：一个输入框自动识别仓库/Release 页面地址或附件链接。预览时显示每个文件的大小，失效的链接（GitHub 返回 404）会直接标为无效。
- **列表**：字号加大；已完成、未完成、我的软件、更新动态都可以选每页 10 / 20 / 50 / 100 条；失败任务在行内显示原因，并提供「重试」。
- **设置**：分类改为左侧竖排，支持搜索；普通设置改完立即保存，网络代理和镜像单独保存，并提示重启。
- **外观**：可选浅色、深色或跟随系统；主题色可选蓝色（默认）、青绿、紫色、石墨；界面缩放可选 90% / 100% / 110% / 125%；动效统一，并可以关闭。
- 消息提示移到窗口顶部。后台下载完成的提醒重新设计：显示文件、项目、版本、大小和用时，可以直接打开文件夹。

### 下载与网络

- **多连接分段下载**：大于 2 MB 的文件默认用 4 个连接分段下载，可在设置里改为 1–8 个。同一文件实测从 66 秒缩短到 19 秒（与网络有关），结果文件逐字节一致，并通过官方 SHA-256 校验。
- **自定义镜像**：可以添加最多 8 个 HTTPS 加速地址，与内置线路一起测速、自动选择。
- 修复网速低于约 50 KB/s 时，所有线路测速都超时、任务停在「等待网络」的问题。
- 网络代理：直连、系统代理，或无账号密码的 HTTP/HTTPS 代理。
- 附件按平台、架构和安装版/便携版偏好匹配，只有唯一匹配时才自动勾选。

### 关注与 Agent

- 更新动态：按时间列出关注项目的新版本，可以标为已读、忽略此版本，并支持分组和标签。
- 关注清单可以导出和导入，迁移到另一台电脑时会先预览冲突。
- 本机 Agent 接入（默认关闭）：DeepSeek Harness 原生插件和 MCP 共用 13 个工具；允许的下载目录改为从资源管理器选择。插件在独立仓库 [dsh-githubsp](https://github.com/lkuliuying/dsh-githubsp) 维护，v0.7.2 可配合本版使用。

## 下载与运行

| 附件 | 用途 |
| --- | --- |
| `GitHubSP-v0.4.0-windows-x64-Setup.exe` | Windows x64 安装版；缺少 WebView2 时下载并安装 Evergreen Runtime。 |
| `GitHubSP-v0.4.0-windows-x64-Portable.zip` | 免安装版；解压完整目录后运行 `GitHubSP.exe`，需要系统已有 WebView2。 |
| `SHA256SUMS.txt` | 校验上述两种分发文件的 SHA-256。 |
| `LICENSE`、`THIRD_PARTY_NOTICES.md`、`FRONTEND-LICENSES.txt`、`RUST-LICENSES.txt` | 项目及第三方许可。 |

请先完全退出旧版（包括托盘图标）再启动新版。v0.4.0 沿用原有数据目录和数据格式，v0.3.1 的下载记录、收藏和设置会直接保留。普通安装和免安装模式沿用正式数据位置；需要随身数据时，在 exe 旁创建空文件 `portable-mode.flag`，使用同目录的 `data/`。独立试用可以使用 `--data-dir <绝对路径>`。

注意：
- 换回 v0.3.1 之前，请先完成或取消进行中的下载。新版最多分 8 段下载，旧版只认 2 段。
- 如果你安装过开发期间标为 v0.7.0 的本地测试包，安装器可能把 v0.4.0 当作较旧版本。遇到这种情况，先卸载测试包再安装；数据目录不会被删除。
- 程序不会自动安装更新，也不会运行下载的文件。

## 验证边界

- 发布前回归：核心 142 项、Tauri 宿主 9 项、前端 8 项测试，以及生产构建、Clippy、格式检查和安装包打包。
- 各轮界面改动都用隔离数据，在真实桌面程序（WebView2 + IPC）中操作并截图核对：多种窗口宽度、深浅主题和全部主题色。
- 分段下载和镜像用真实公开附件测速对比。
- 完整的桌面验收脚本（`verify-desktop-ui.cjs` 等）已按新界面调整，但没有在发布前从头重跑。
- 程序未进行 Windows 代码签名。干净系统上的安装/卸载、缺失 WebView2、多 DPI/多显示器尚未专项验收。

详细的页面对照和每轮试用反馈见[界面重构说明](../design/2026-11-18-software-centric-ui.md)，开发阶段记录见 [milestones](../milestones/README.md)。
